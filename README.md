## Local Development

```sh
npm ci
npm run dev
```

## Validation and Production Build

```sh
npm run typecheck
npm run lint
npm run build
npm run preview
```

The production build checks TypeScript types before generating the `dist/` directory.
React components and content containing JSX use `.tsx`; helpers and shared types use `.ts`.
Application types are defined in `src/types.ts`. Browser and build configuration code
are checked separately through `tsconfig.app.json` and `tsconfig.node.json`.
ESLint and PostCSS retain their JavaScript configuration files.
